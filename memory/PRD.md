# ALT&ACT Website - PRD

## Problem Statement
Site associatif ALT&ACT (www.alt-act.eu) hébergé sur OVH, code source sur GitHub (https://github.com/Luximon777/www.alt-act.eu, branche gh-pages).

## Architecture
- **Frontend**: React.js avec HashRouter, Tailwind CSS, shadcn/ui
- **Backend**: FastAPI (Python)
- **Database**: MongoDB
- **Hosting**: OVH (production), Emergent (preview)
